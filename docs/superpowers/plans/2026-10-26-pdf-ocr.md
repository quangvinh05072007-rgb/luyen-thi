# Local scanned PDF import

Goal: Import scanned exam PDFs with no AI key and retain all diagrams and formulas visually.

Implementation: render scanned pages using PDF.js and canvas; OCR locally with Tesseract Vietnamese/English models installed alongside the app. Detect question starts and part headings, crop original question regions (including continuations), and use those images as the canonical question content. Keep OCR text separately for review/search; never present OCR math as verified LaTeX. Preserve interactive A–D / a–d options with references to the original image. Use text answer sections only as answer keys, never as questions. Reuse existing image storage, draft review, editing, exam rendering and Word export.
